# @my-games/sudoku-core

> 数独引擎核心，纯 TypeScript、无框架依赖。**当前为 `0.0.0` 占位版本**，
> 仅导出占位常量，用于种下 npm 首版并配置 Trusted Publisher。

```bash
pnpm add @my-games/sudoku-core
```

```ts
import { SUDOKU_PACKAGE, SUDOKU_STAGE } from '@my-games/sudoku-core';
```

真实引擎（`Sudoku` 类 + 求解器 + 生成器 + 存档）将在占位包发布后作为后续提交补入。
产出 ESM / CJS / UMD / IIFE 四格式；IIFE/UMD 全局名 `SudokuCore`。样式：`@my-games/sudoku-core/style.css`。

完整说明见仓库根 README：<https://github.com/my-gam/sudoku#readme>
